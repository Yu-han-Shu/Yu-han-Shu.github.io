GRAPHICS · GEOMETRY · NAVIGATION3D

RealityScan
UV-to-3D Navigation

A geometry pipeline that maps image coordinates into reconstructed 3D scenes and plans collision-aware paths through point clouds.

The saved evaluation covers 25 navigation paths across five scenes, with no collision violations among 4,172 checked path points.

Results apply to the released test scenes; source reconstruction data must be prepared separately.

PythonOpen3DCOLMAP
